# SGXray

A portfolio tracker for beginner investors in Singapore.

Track your SGX stocks, REITs and ETFs, see your dividends and total return,
and find out whether you're beating the STI, with every number explained in plain English.

> 🚧 Work in progress. Building in December 2026.

## Planned features

- Record buys, sells and dividends
- Daily prices for SGX tickers, saved locally
- Total return including dividends
- Dividend calendar and 12-month income forecast
- Your portfolio vs the STI ETF
- Plain-English explanations for every metric

## Built with

Python, SQLite (SQL), pandas, yfinance, Flask
